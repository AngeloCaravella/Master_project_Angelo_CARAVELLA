This file provides example commands for running the new `sensitivity_analysis.py` script.

# --- Example Commands ---

## 1. Basic Dry Run

This is the recommended first step to test your setup. It generates the experiment plan and example configuration files without running any simulations.

```sh
python sensitivity_analysis.py --base-config ev2gym/example_config_files/base_scenario.yaml --dry-run
```

- `--base-config`: Specifies the template configuration for the experiments.
- `--dry-run`: Tells the script to prepare everything but stop before executing the simulations.
- It will use the default sampling mode (`morris`) and budget (`medium`).


## 2. One-Factor-at-a-Time (OFAT) Analysis

This command runs a simple OFAT analysis with a small budget, executing up to 4 simulations in parallel.

```sh
python sensitivity_analysis.py --base-config ev2gym/example_config_files/base_scenario.yaml --mode ofat --budget small --parallel 4
```

- `--mode ofat`: Selects the OFAT sampling strategy.
- `--budget small`: Translates to a small number of simulations (e.g., 50), suitable for a quick overview.
- `--parallel 4`: Uses 4 CPU cores to run simulations concurrently.


## 3. Latin Hypercube (LHS) Analysis for a Large-Scale Campaign

This command runs a large-scale LHS campaign, saves the results in a custom directory, and sets a random seed for reproducibility.

```sh
python sensitivity_analysis.py --base-config ev2gym/example_config_files/base_scenario.yaml --mode lhs --budget large --out sensitivity_lhs_results --seed 12345
```

- `--mode lhs`: Selects the Latin Hypercube Sampling strategy for efficient space coverage.
- `--budget large`: Translates to a large number of simulations (e.g., 1000) for a detailed analysis.
- `--out sensitivity_lhs_results`: Specifies a custom name for the output folder.
- `--seed 12345`: Fixes the random seed, ensuring that the exact same set of experiments can be run again.


## 4. Morris Screening Focused on Specific Metrics

This command runs a Morris screening analysis but tells the post-processing step to generate plots and analysis only for the `revenue` and `congestion_count` metrics.

```sh
python sensitivity_analysis.py --base-config ev2gym/example_config_files/base_scenario.yaml --mode morris --budget medium --metrics-list revenue congestion_count
```

- `--mode morris`: Selects the Morris method, which is excellent for identifying the most influential parameters.
- `--budget medium`: A balanced number of runs (e.g., 200).
- `--metrics-list revenue congestion_count`: Focuses the final report and plots on these specific outcomes, which is useful when your simulation produces many metrics.
